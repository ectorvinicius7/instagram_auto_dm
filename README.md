# Instagram Auto DM

Aplicação desenvolvida em Python para automatizar o envio de mensagens privadas no Instagram a partir de comentários em publicações.

## Objetivo

O projeto tem como objetivo identificar comentários que contenham uma palavra-chave específica (como "LINK") e enviar automaticamente uma mensagem privada ao usuário, utilizando a API oficial do Instagram da Meta.

## Tecnologias utilizadas

- Python
- Flask
- API do Instagram (Meta)
- Webhooks
- SQLite

## Funcionalidades

- [x] Estrutura inicial da aplicação Flask
- [x] Rota inicial
- [x] Rota de callback do Instagram
- [ ] Autenticação com a API do Instagram
- [ ] Recebimento de notificações por Webhooks
- [ ] Identificação de comentários por palavra-chave
- [ ] Envio automático de mensagens privadas
